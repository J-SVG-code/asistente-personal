# JARVIS Local AI 🚀

Asistente de inteligencia artificial progresivo (PWA) diseñado para operar de forma autónoma y fluida en dispositivos móviles, con soporte dual online/offline mediante Service Worker.

## Características
- **Modo PWA:** Instalable directamente como aplicación nativa en la pantalla de inicio de Android (Google Chrome).
- **Soporte Offline:** Almacenamiento en caché local para mantener la operatividad sin conexión a internet.
- **Motor Inteligente Integrado:** Respuestas dinámicas y fluidas integradas de forma nativa.

## Estructura del Proyecto
- `index.html`: Interfaz de usuario y núcleo conversacional.
- `manifest.json`: Configuración de la aplicación web progresiva.
- `sw.js`: Service Worker para la gestión de red y caché.
